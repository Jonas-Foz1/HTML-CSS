- Existem niveis e subniveis de titulos
- isso cria hierarquias nos titulos
- não posso pular do nivel 1 para o nivel 3
- precisa respeitar a hierarquia
- usamos h1-h6 para criar essas hierarquias em HTML
- n]ao se trata de tamanho de texto - é somente a hierarquia dos temas
- mudar tamanho do texto é possivel com CSS - não misturar as ferramentas
