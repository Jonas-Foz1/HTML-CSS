### Como funcionam a HTML e as CSS
- a linguagem HTML
- AS folhas de estilo
- elas nao sao linguagens de programação
- correto é falar: desenvolvo em HTML e CSS
- HTML = hypertext markup language
	- hypertext = um texto clicavel que leva para outtos
	- markup = usa marcadores para desenvolver
- CSS = cascading style sheets
	- folhas de estilo em cascata - seletores adicionam em cascata novas caracteristicas
- HTML é uma linguagem focada em **conteudo**
	- textos
	- iamgens
	- videos
	- tabelas
- CSS é foco em **Design**
	- cores
	- sombras
	- tamanhos
	- posicionamento
- JavaScript é uma linguagem de programação que cuida das **interações**
- As 3 linguagens em conjunto são fundamentais para um site
	- menus
	- animações
	- popups
	- validações
### Conteudo em HTML
- Exemplo de titulo - conteudo
- para fazer isso, precisa de tags
- <h1> Exemplo de Titulo </h1>
- <p> Exemplo de paragrafo </p>
- <img.src="foto.png" alt="Exemplo de foto">
- alt = parametro
- "Exemplo de Foto" = valor
- se nao conseguir mostrar a imagem, vai mostrar o texto com "exemplo de foto"

### Estilo em CSS
- CSS é design
- geralmente ta dentro de uma tag style
- h1 {font-family: Arial;
- font-size: 20pt;
- color: blue;}
- h1 = seletor
- conteudo do colchete = declaração
- color = propriedade
- blue = valor
- *toda declaração tem que terminar com ponto e virgula*

### Estrutura basica de um documento HTML
<!DOCTYPE html>
<html lang="pt-br">
	<head>
		<meta charset="UTF-8">
		<meta name="viewport">
		content="width=device-width", initial-scale=1.0">
		<title>Document</title>
	</head>
	<body>
		<h1>Olá, Mundo!</h1>
	</body>
</html>
