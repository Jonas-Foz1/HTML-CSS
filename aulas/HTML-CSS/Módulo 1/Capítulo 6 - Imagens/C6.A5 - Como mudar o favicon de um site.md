- Favicon - icone que aparece ao lado do header do site no topo do navegador
- para baixar icones prontos - http://www.iconarchive.com/
- para criar icones do zero - https://www.favicon.cc/
- para criar icones com base em imagens que ja possuo - https://favicon.io/

### Como usar icones
- no codigo, acima do title, escrever link > favicon
- onde está o favicon.ico, colocar o nome do arquivo a ser utilizado
- atenção com o cache do navegador e do windows - ele vai armazenar o primeiro icon carregado
