### Mark
- vc Pode usar a tag MARK para destacar um texto
- Para mudar a cor do mark, podemos usar CSS
- Colocar parametro STYLE
- Para fazer isso, dentro da tag vc escreve STYLE > seleciona BACKGROUND COLOR > escolhe a cor
- isso muda a cor somente de 1 TAG por vez
- para replicar para varias tags, precisa colocar style em todas elas
- dica para fazer mais rapido: no começo do head (abaixo do titulo), criar um seletor de style
	- style
		- mark {
			- background-color: limegreen;
		- }
- Não vai servir para marks de outras paginas, mas tem uma forma mais avançada usando link externo
