- **só funciona se estiver no servidor**

- Precisar criar um **dominio**
- precisa criar uma **hospedagem**

### Dominio
- precisa ser um nome unico
- pago anualmente
- varios TLDs - Top level domains

### Hospedagem
- espaço para armazenar arquivos
- pago mensalmente
- escolher por espaço, quantidade de memoria, recursos

### URL
- Uniform Resource Locator - só aponta para um lugar
- dentro de uma URL, temos partes
- Ex: www.github.com/gustavoguanabara
- github.com = dominio
- .com = TLD. No caso do .com é um GTLD - generico
- .br = CCTLD - para identificar locais (country code)
- www = subdominio. Pode ser outro subdominio
- depois da / = caminho.
- Exercicio: gustavoguanabara.github.io
	- gustavoguanabara = subdominio
	- github.io = dominio
	- .io = TLD
