
### Representação de Dados

- 0s e 1s = dígitos binarios = bits
- funciona para qualquer equipamento eletronico
- ficamos bem limitados com isso
- computaçao usa uma sequencia de 8 bits para representar algum dado
- byte = 8 bits = porção minima que pode representar uma determinada informação
- ex: 01000001 = A
- Procurar código multibyte **UTF - 8?** 
- Computador só entende ondas binarias (ou quadradas)
- 1024 bytes = 1KB (2 elevado a 10)
- 1024 KB = 1MB
- 1024 MB = 1GB
- 1024 GB = 1TB
- 1024 TB = PB
- ....
- **Importante** - MB é diferente de Mb
- B maiusculo = bytes
- B minusculo = bits
- bytes normalmente associamos a tamanho, bits normalmente transmissão

### Como nos conectamos?
- Cliente > modem > internet
- o modem faz **modulção** e **demodulação**
- ele transforma a onda quadrada em onda senoidal, e vice-versa

### Como acessamos servidores?
- cliente tem um endereço IP
- Servidor tem outro endereço IP
- como conectar aos servidores sem usar o endereço IP?
- usando uma "agenda eletronica" - chamada de **DNS - Domain Name System**
- O Modem Contacta o DNS, ele devolve o endereço IP do servidor buscado, e ai o modem se conecta ao servidor

### Como funcionam as rotas?
- Cada pacote transmitido pode seguir uma rota
- rotas podem ser mais diretas ou mais demoradas
- isso impacta na velocidade percebida de carregamento dos sites
