### Front-end e Back-end
- client-side = front-end
- é diferente do designer
- designer pensa na estrutura, cores, tamanhos
- front-end pega a "receita" e desenvolve em HTML e CSS
- Back-end = server-side
- mais interessado na interação do codigo com as entranhas do servidor

### Linguagens Back-end
- php
- JavaScript
- Java
- Python
- C#
- exemplo: cliente quer entrar em uma loja online de camisetas
- informações das camisetas dispoinivies, cores, tamanhos etc, estão salvas num banco de dados
- o cliente vai fazer uma solicitação, o php vai consultar no banco de dados e vai retornar isso para o cliente com HTML e CSS

### Linguagens front-end
- HTML
- CSS
- JavaScript
