- abrir pastas e arquivos usando o VS code
- usar ! para criar codigos automaticamente
- head = configurações site
- body = conteudo site
- !DOCTYPE html = Essa linha não é uma tag HTML — é uma **declaração** que avisa ao navegador qual versão do HTML está sendo usada. No caso, `html` (sem número) indica o **HTML5**, que é a versão moderna e atual.
- Sem ela, o navegador pode entrar em um modo chamado _quirks mode_ e renderizar a página de forma inconsistente entre diferentes navegadores.
- meta = serve para fornecer **informações sobre o documento** para o navegador (e para mecanismos de busca). Ela fica no `<head>` e não aparece visualmente na página.
	- UTF-8 = padrao de configuraçao de caracteres que aceita sinais graficos e acentuações
	- viewport = site vai ocupar 100% da tela disponivel no navegadior
- usar as tags salvas do code para escrever mais rapido
- Head = o que vai aparecer na aba do navegador
- Body = conteudo da pagina, todo o resto
