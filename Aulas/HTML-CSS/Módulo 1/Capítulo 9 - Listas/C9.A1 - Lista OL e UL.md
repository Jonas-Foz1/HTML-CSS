- É possivel criar listas ordenadas e não-ordenadas no HTML

### Listas Ordenadas
- Tag: OL para delimitar lista
- Tag: LI para identificar itens da lista
- a Tag OL possui o parametro TYPE para configurar o tipo de marcador?
	- 1 - valor padrão - listas numeradas 1,2,3,4...
	- A - listas alfabeticas em maiusculas A,B,C,D...
	- a - listas alfabeticas em minusculas a,b,c,d...
	- I - listas com algarismos romanos em maiusculas I, II, III, IV...
	- i - listas com algarismos romanos em minusculas i, ii, iii, iv...
- Tambem é possivel usar o parametro START para mudar o item inicial
	- ele é numerico: sempre usar numero para mudar o item inicial, mesmo que seja letra
### Listas Não-ordenadas
- Tag: UL para delimitar lista
- Tag: LI para identificar itens
- Types:
	- disc - bolinha preta
	- circle: circulo preto
	- square - quadrado preenchido
