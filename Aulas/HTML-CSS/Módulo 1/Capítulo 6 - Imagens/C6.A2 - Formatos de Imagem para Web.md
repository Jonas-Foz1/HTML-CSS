- para editar imagens, é possivel usar o **GIMP** - Ferramenta open source
- https://www.gimp.org/downloads/
- não é igual o photoshop, mas é gratuito e ajuda para fazer coisas simples de imagem

### Formatos de Arquivo
- para web, usamos normalmente JPEG e PNG
- qual esclolher? depende da necessidade
- JPEG foi criado em 1983 e consegue compactar uma imagem melhor
	- para fotos grandes - JPEG
- PNG é mais recente, 1993, e é um formato para substituir o GIF
	- permite controlar transparencia de pixels
	- a qualidade é maior, mas fica mais pesada para carregar no site
- Para sites, é sempre importante pensar no tamanho das imagens para evitar problemas de carregamento

### Cuidados com peso de imagem
- quanto mais o tamanho em pixels, mais pesada vai ficar
- usar imagens no tamanho exato para os sites
- se precisar cortar, usar o GIMP para reduzir
- reduzir somente no carregador vai deixar o site ainda mais pesado
