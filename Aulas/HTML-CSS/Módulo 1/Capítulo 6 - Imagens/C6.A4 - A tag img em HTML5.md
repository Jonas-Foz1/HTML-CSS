- Criar o exercicio 3 e baixar as imagens do repositorio de exercicios
- no VSCode, criar o index.html e colocar as infos
- para carregar imagens, a tag é **img**
- ela é quebrada em duas partes
	- src = source (a imagem original)
	- alt = alternative (nome alternativo para a imagem no site, caso não seja carregada)
- Para puxar todos os arquivos de dentro de uma pasta (para facilitar busca de imagens)
	- usar ctrl + espaço - abre um dropdown de todos os arquivos dentro da pasta no VS CODE
- Se vc pegar uma imagem muito grande, pode cortar ela no GIMP
	- abrir imagem no gimp
	- procurar ferramenta de corte (guilhotina)
	- selecionar a parte que quer manter da imagem
	- apertar ENTER
- Podemos carregar imagens direto da pasta raiz, de uma pasta dentro da raiz ou ate mesmo de uma URL, buscando uma imagem na internet
