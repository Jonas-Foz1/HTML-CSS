### Negrito
- jeito errado: usar a tag b para negrito
- jeito certo: usar a tag strong

### Itálico
- jeito errado: usar a tag i para italico
- jeito certo usar a tag em (emphasis)

Em ambos os casos, estamos focando na semantica das palavras, e não na forma

### Truque para escrever codigos
- Selecionar o texto que quer colocar entre tags
- usar **ctrl+shift+p**
- buscar por **wrap with abbreviation**
- escrever a tag desejada
- apertar **ENTER**

### Tags Usadas
- strong
- em
