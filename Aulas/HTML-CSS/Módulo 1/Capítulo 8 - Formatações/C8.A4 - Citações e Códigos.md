### Código-fonte
- Escrever codigos usando a fonte normal do HTML é ruim, pois a fonte não é mono-espaçada
- uma forma de fazer isso é envelopar o texto com a tag CODE
- essa fonte é otima para ler códigos
- importante: o CODE não organiza o código com indentação
- para fazer isso, precisamos usar a tag PRE envelopando o CODE
- com isso, os textos vão considerar as quebras de linha
- para tirar os espaços a esquerda do codigo:
	- selecionar o codigo > shift+tab
	- para recuar: selecionar codigo > tab


### Citações
- para citações, podemos usar Q
- Tag: Q (Quote)
- usar isso para dar SENTIDO de citação
- isso para citações simples, sem quebra
- existem as citações completas
- Tag: BLOCKQUOTE
- usar isso para citar livros por exemplo
- Alem disso, é possivel deixar referenciado o livro citado:
- Tag: CITE (link do livro)

### Abreviações
- Tag: ABBR
- Usando essa tag, é possivel deixar explicações de abreviações na pagina
